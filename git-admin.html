WORDPRESS-STYLE GITHUB PAGES AUTO-PUBLISHER

Connect Admin Panel to Your GitHub Repository

Enter your GitHub repository and Personal Access Token once. Whenever you click "Publish Live to GitHub", this Admin Panel updates the public content, landing cards, page HTML and SEO together in your GitHub repository so your public website (salucommunity.github.io) updates automatically for all students!

HOW IT WORKS ON GITHUB PAGES

3 Easy Steps (Just Like WordPress wp-admin)

  1. Create a token (one time): On GitHub open Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token. Under Repository access choose Only select repositories and pick your website repository. Under Permissions set Contents to Read and write. Copy the token and paste it on the left.
  2. Edit Anything in This Admin Panel: Add or delete Announcements, Merit Lists (PDF links), Fees, Scholarships, Departments, Seats, or Mock Test Results in the tabs above.
  3. Publishing is automatic: a few seconds after each change, this panel commits the updated public content and pages to your repository through the official GitHub API. GitHub Pages deploys the committed changes next. You can also press Publish Live at any time.
