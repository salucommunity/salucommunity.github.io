# Whole-paper imports and optimised uploads

See **SALU-JOBSHUB-GUIDE.md** for installation and the current Jobs Hub / results controls.

## Import all questions together

Select a category and a new or existing test in Jobs Preparation or Mock Test Library. Choose a question file or paste the complete paper. Click Import all questions, review the total and Publish Live. You do not need to save each question separately.

Supported formats are CSV, TSV, JSON, TXT/Markdown, XLSX, typed DOCX and selectable-text PDF. CSV/TSV/Excel use Question, A, B, C, D and Answer columns; Subject, Explanation, Test, Category, Description and Duration are optional. JSON can contain one paper or several tests. TXT uses numbered questions with lettered options and Answer lines; a separate answer key is supported. Templates are included in Question-Import-Templates.

Every question needs 2-6 non-empty options and a correct answer. Invalid batches change no existing questions. Appending skips exact duplicates and rejects conflicting answers. Replace intentionally swaps a selected paper's question set. Scanned/image-only PDFs need OCR before question extraction, but may still be uploaded as preparation files.

Use up to 3,000 questions in one import and 15,000 questions across the test bank. Larger drafts use the existing browser draft store. Publish and download backups to preserve copies beyond the browser.

## Images and files

Standard image/PDF tools show the actual size reduction and keep the original when optimisation would be larger. Signed PDFs and protected document structures retain their existing preservation handling. Advertisement and popup images use a higher-resolution profile with a quality floor to keep document text readable. Complex adverts can remain larger than the target size.

Save a job notice or popup image to upload its optimised image to the connected GitHub repository. Publish Live makes the notice or popup settings public. Preparation files can still be uploaded in batches through the existing Jobs tools.

## Test PDF

Select a created test in the admin and choose Download test PDF. The complete solved paper uses the SALU paper design, selected test title, jobshub.html address and Hub contact number. Student test pages retain the submitted-result and WhatsApp group flow.
