# Test experience and results

Use **SALU-JOBSHUB-GUIDE.md** for installation and the latest controls.

Students enter a required name and city, plus an optional contact number. One question appears at a time with Previous and Next controls. Answers remain selected when moving back. Normal test-exit navigation asks for confirmation; refresh/close uses the browser warning. Interrupted attempts can resume with their original deadline.

The server calculates and saves the submitted result. Connection failures offer a retry without duplicating the result. After submission, students see their score, review answers and use the free/premium WhatsApp group links configured in Test Results & Groups.

The admin now displays results separately for each test. Each candidate table has one Download PDF button above it, containing every candidate's name, contact, city and result. There are no individual result Save or View buttons. Search filters the on-screen table; the PDF still includes all candidates belonging to the test. A failed result page stops the export rather than creating a partial report.

The existing private results service is reused. Candidate records never enter public data.js. The main website still needs Publish Live to activate installed file updates.
